# Security policy

[简体中文](SECURITY.zh-CN.md) · **English** · [日本語](SECURITY.ja.md)

Do not report vulnerabilities through public issues. Until a private security contact is published, contact the repository owner privately through GitHub.

AnyWork installation never executes code contained in a Skill. Treat Skill scripts and references as untrusted until reviewed. External writes, message sending, publishing, deletion, credential use, and permission expansion require explicit user authorization.

Reports should include the affected version, platform, agent, reproduction steps, impact, and any safe proof of concept. Do not include real secrets or personal data.

The project targets acknowledgement within 48 hours and initial severity classification within seven days. These are response targets, not guarantees.
