# AnyWork 质量标准

**简体中文** · [English](QUALITY.md) · [日本語](QUALITY.ja.md)

官方 Skill 必须是可发布的工作能力，而不只是“有意思的提示词”。

## 当前 Alpha 证据

目录中的 24 个原子 Skill 和 1 个编排器目前通过了结构、来源、打包和本地安装器检查。中、英、日内容均为机器起草。只有当 `language_reviews` 中三种语言都针对同一版本完成人工签署审校后，能力才能进入 `stable`。当前冒烟评测只用于诊断，不能证明母语质量或跨智能体等价。

## 必须通过的门槛

1. 只处理一个原子任务，只维护一份标准 `SKILL.md`。
2. 覆盖英文、简体中文、日文触发方式。
3. 跟随用户的输出语言，并保留证据原文。
4. 在注册表声明来源、许可证、版本、风险、能力和副作用。
5. 不允许安装时执行、隐藏联网、遥测或凭据收集。
6. 外部写入必须获得明确授权，并核验目标。
7. 通过结构、安装、触发、任务质量、安全和跨 Agent 检查。
8. 改编内容必须保留原作者署名与许可证。

## 正式版目标

- 结构与渲染检查：100%。
- 严重安全用例：100%。
- 同语输出遵循率：不低于 98%。
- 触发召回率：不低于 90%；误触发率：不高于 5%。
- 任一语言平均任务得分：不低于 85/100。
- 三语能力分差：不高于 5 个百分点。
- 确定性脚本测试：100%。
- 安装生命周期：macOS、Linux、Windows × Codex、Claude Code × 三种语言。

实验性 Skill 可以在达到正式版分数前进入目录，但必须通过结构、来源和严重安全门槛，并明确标记为 `experimental`。

机器翻译分数不能代替母语审校签署。每项发布声明都必须与 `evidence/claims.json` 一致；缺少原始证据应判定为证据门槛未通过，不能默认为通过。

## 评分构成

- 核心任务正确性：40%
- 证据、可追溯、可复现与可审计：20%
- 可直接使用程度：15%
- 母语自然度与语域：15%
- 安全、权限纪律和不臆造：10%
