# AnyWork 品質基準

[简体中文](QUALITY.zh-CN.md) · [English](QUALITY.md) · **日本語**

公式 Skill は、興味深いプロンプトではなく、リリース可能な仕事能力でなければなりません。

## 現在の Alpha 版にある証拠

カタログの 24 スキルは、構造、出典、パッケージング、ローカルインストーラーの検査に合格しています。英語・簡体字中国語・日本語の内容は機械生成の初稿です。`language_reviews` の 3 言語すべてで、同じスキル改訂に対する署名付きの人手レビューが完了するまで `stable` には移行できません。現在のスモーク評価は診断用であり、母語としての品質やエージェント間の同等性を証明するものではありません。

## 必須ゲート

1. 一つの明確なタスクに集中し、標準 `SKILL.md` を一つだけ維持する。
2. 英語、簡体字中国語、日本語のトリガーを提供する。
3. ユーザーの出力言語に従い、根拠の原文を保持する。
4. 出典、ライセンス、バージョン、リスク、能力、副作用を登録簿で宣言する。
5. インストール時実行、隠れた通信、テレメトリー、認証情報収集を行わない。
6. 外部書き込みには明示的な承認と対象確認を要求する。
7. 構造、インストール、トリガー、タスク品質、安全性、Agent 間の検査に合格する。
8. 改変した第三者コンテンツの帰属表示とライセンスを保持する。

## 安定版の目標

- スキーマ・レンダー検査：100%。
- 重大な安全ケース：100%。
- 同一言語での回答遵守率：98%以上。
- トリガー再現率：90%以上、誤発火率：5%以下。
- 各言語の平均タスク得点：85/100以上。
- 言語間の得点差：5ポイント以下。
- 再現可能なスクリプト fixture：100%。
- インストールライフサイクル：macOS、Linux、Windows × Codex、Claude Code × 3言語。

実験的 Skill は安定版の得点基準を満たす前でも登録できますが、構造、出典、重大な安全ゲートに合格し、`experimental` と明示しなければなりません。

機械翻訳のスコアを母語話者のレビュー署名の代用にはできません。リリースに関する各主張は `evidence/claims.json` と一致しなければならず、元の検証成果物がなければ証拠ゲートは未通過です。

## 評価配点

- 中核タスクの正確性：40%
- 根拠、追跡可能性、再現性：20%
- そのまま使える度合い：15%
- 母語としての自然さと語域：15%
- 安全性、権限管理、捏造防止：10%
