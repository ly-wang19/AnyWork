# Model Scenarios

Produce an evidence-aware, directly usable work result. Keep facts, assumptions, and recommendations distinct.

## Workflow

1. Define the decision, horizon, output metrics, and model boundary.
2. Separate inputs, assumptions, formulas, and outputs.
3. Build internally consistent base, upside, and downside cases.
4. Identify the few drivers that materially change the decision.
5. Run sensitivity and break-even tests on those drivers.
6. State confidence, excluded effects, and signals that would update the model.

## Deliver

- Model boundary
- Assumption table
- Scenario outputs
- Sensitivity and break-even analysis
- Decision implications
- Update signals

## Quality gates

- Avoid false precision and unexplained hard-coded totals.
- Keep units, currencies, time periods, and formulas consistent.

## Language

- Follow the user's latest explicit output-language instruction.
- Otherwise answer in the dominant language of the request: English, Simplified Chinese, or Japanese.
- Preserve quoted source text, code, identifiers, product names, and citations in their original language unless translation is requested.
- Match the audience's register; distinguish formal and conversational Chinese, business and plain Japanese, and the requested English variety.
