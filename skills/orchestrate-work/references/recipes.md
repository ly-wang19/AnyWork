# End-to-end recipes

Use these as starting points, not mandatory pipelines. Remove unnecessary stages and insert a blocking clarification or permission gate when the evidence requires it.

## Research to recommendation

Trigger examples: “Research this market and recommend an entry strategy.” / “调研这个市场并给出进入建议。” / 「この市場を調査し、参入案を提案して。」

`clarify-outcome` → `gather-sources` → `verify-claims` → `synthesize-sources` → `compare-options` → `make-decision` → `write-brief` → `review-deliverable`

Handoff: question contract → source log → claim ledger → evidence synthesis → option matrix → decision record → brief → checked brief.

## Data to executive presentation

Trigger examples: “Analyze these results and turn them into an executive deck.” / “分析这些结果并做成高管汇报。” / 「この結果を分析し、経営層向け資料にして。」

`extract-structured-info` → `analyze-data` → `model-scenarios` when needed → `build-spreadsheet` when recalculation matters → `design-presentation` → `review-deliverable`

Handoff: structured records → reproducible findings → scenario assumptions → workbook → slide narrative → rendered review.

## Meeting to accountable execution

Trigger examples: “Run the planning meeting and turn it into owned work.” / “把规划会开好并落实成责任到人的行动。” / 「計画会議を設計し、担当付きの実行項目まで整理して。」

`prepare-meeting` → meeting occurs → `capture-decisions-actions` → `plan-work` → `prioritize-work` → `review-deliverable`

Handoff: agenda and pre-read → notes or transcript → decision/action log → executable plan → sequenced backlog → checked operating record.

## Recurring process to safe automation

Trigger examples: “Fix this recurring operation and automate it safely.” / “解决这个反复出现的运营问题并安全自动化。” / 「繰り返す運用問題を解決し、安全に自動化して。」

`diagnose-root-cause` → `create-sop` → `automate-routine` → controlled run → `run-retrospective`

Handoff: tested causal model → controlled manual procedure → idempotent automation with recovery → run evidence → owned improvement experiments.

## Global content launch

Trigger examples: “Turn this approved position into launch content for China, Japan, and the US.” / “把已确认主张做成面向中美日的发布内容。” / 「承認済み方針を中国・日本・米国向けの公開コンテンツにして。」

`write-brief` → `draft-document` or `design-presentation` → `localize-content` → `write-message` → `review-deliverable`

Handoff: approved content contract → master artifact → locale-specific artifacts → channel messages → checked launch set.

## Vendor or tool selection

Trigger examples: “Evaluate these vendors and give me an auditable final choice.” / “评估这些供应商并给出可审计的最终选择。” / 「候補ベンダーを評価し、監査可能な最終案を出して。」

`clarify-outcome` when criteria are unclear → `gather-sources` → `verify-claims` → `compare-options` → `make-decision` → `write-brief`

Handoff: decision criteria → evidence set → verified claims → comparison matrix → decision record → approval-ready brief.
