# Diagnose Root Cause

Produce an evidence-aware, directly usable work result. Keep facts, assumptions, and recommendations distinct.

## Workflow

1. Describe the failure, expected state, impact, start time, and affected scope.
2. Separate symptoms from direct causes, contributing conditions, and system causes.
3. Generate competing hypotheses instead of committing to the first story.
4. Rank hypotheses by evidence, explanatory power, and cost of testing.
5. Design discriminating tests and gather evidence safely.
6. Recommend containment separately from corrective and preventive action.

## Deliver

- Problem statement
- Evidence timeline
- Competing hypotheses
- Tests and results
- Root cause or current uncertainty
- Containment and prevention

## Quality gates

- Do not label a person as the root cause of a system failure.
- State when evidence supports only a probable cause.

## Language
